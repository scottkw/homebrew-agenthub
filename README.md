# homebrew-agenthub

> [!WARNING]
> **Deprecated.** [AgentHub](https://github.com/scottkw/agenthub) is no longer maintained, and its cask has been removed from this tap.

If you installed AgentHub through this tap, uninstall it and remove the tap:

```sh
brew uninstall --cask agenthub
brew untap scottkw/agenthub
```
